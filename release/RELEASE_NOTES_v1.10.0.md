# Dual Hat 1.10.0 Release Notes

Dual Hat 1.10.0 requires Architecture to provide a brief human-readable report whenever a governed phase or subphase closes and work transitions onward. The report summarizes what was done, what materially resulted, what remains limited or carried forward, and why the next destination follows.

Machine evidence and status updates remain authoritative inputs, but they no longer substitute for the stakeholder-facing narrative. This is a backward-compatible additive governance update.
