# Dual Hat 1.12.0 Release Notes

Dual Hat 1.12.0 strengthens design sequencing and active-task continuity.

- Entering a phase or capability no longer implies acceptance of materially consequential design details that remain unsettled. Architecture first exposes and discusses the meaningful product, UX, workflow, commercial, privacy, or architectural choices using the lightest useful artifact, then proceeds without extra ceremony after resolution.
- A side question now creates a concurrent response obligation rather than a pause. The responding role answers it, identifies the execution action still active or immediately resumed, and continues proactive milestone reporting; the answer itself is not a terminal checkpoint.

This is a backward-compatible additive governance release. Existing 1.x authority, lifecycle, schema, and compatibility contracts remain unchanged.
