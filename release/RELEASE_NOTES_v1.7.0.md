# Dual Hat 1.7.0 Release Notes

Dual Hat 1.7.0 is a backward-compatible governance and onboarding release.

It adds a plain-language explanation of the framework before First Use and requires each consuming project to bind Dual Hat's abstract model tiers to evidence-backed concrete selections. Planning, preflight, session handover, and environment-change handling now keep that mapping current without pretending a host can expose or switch models when it cannot.

The release also distinguishes governance coupled to a product capability from independently bounded GOV work and makes minimum sufficient process a cardinal rule. Agents defer repeat-prone lifecycle steps to the latest safe point, reuse still-valid evidence, combine overlapping controls, and validate deltas and affected surfaces before repeating a whole process.

Platform preflight evidence is now dynamically bound to the active work item and excludes its own generated artifact from the governed repository digest. Persisting or committing a preflight therefore no longer invalidates the receipts it contains.

Existing 1.x authority, lifecycle, operating-mode, historical work-item, and mandatory safety contracts remain readable and valid. No material user, Architecture Office, security, privacy, rights, repository-integrity, recovery, or publication safeguard is weakened.
