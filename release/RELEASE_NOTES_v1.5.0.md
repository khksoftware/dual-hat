# Dual Hat 1.5.0 Release Notes

Dual Hat 1.5.0 requires the Architecture Office to propose the next work to
plan after it fully accepts a work item. The proposal identifies the intended
outcome, smallest useful scope, and principal boundaries or decisions so a
successful closure leaves the user with clear forward direction.

The proposal remains planning guidance. It does not itself authorize the next
work item or weaken the normal work-order and approval boundary.

This is a backward-compatible additive minor release. Existing 1.x work-item,
profile, handover, and authority concepts remain available, and no mandatory
control is weakened.
