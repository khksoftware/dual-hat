# Dual Hat 4.2.0 release notes

Dual Hat 4.2.0 is a minor, backward-compatible release. No principle is renumbered, retired or reworded, and no existing citation stops resolving.

Adopters upgrading from 4.1.0 should read principle 3 again. Its systemic-gap catalogue is the part of the framework most often consulted when deciding whether a defect is an instance or a class, and it now names three further shapes drawn from observed failures rather than from theory: a binding severed by a faithful paraphrase; a remedy that closes the appearance of a defect rather than the property; and a detector that substitutes a cheaper question for the real one without saying so where the result is read. Each is a case where a mechanism exists, passes, and protects nothing -- which is harder to notice than a mechanism that is simply missing.

The catalogue no longer states its own length. A count written into prose beside a list it does not derive goes stale the first time the list grows, and that is itself one of the shapes the catalogue names. Anyone quoting "one of four shapes" from 4.1.0 should quote the list instead.

Schema and tooling changes are additive or corrective and require no adopter action.
