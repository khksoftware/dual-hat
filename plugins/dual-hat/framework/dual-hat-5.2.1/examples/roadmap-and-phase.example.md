# Example Roadmap and Phase

Phase `PHASE-1` opens only after its dependency and protected-state checks pass. Capability `CAP-001` delivers one bounded repository correction, must pass its validation and closure gate, and does not authorize `CAP-002`. The phase closes only after outcome evidence, test-health review, debt/deferred reconciliation, detached validation, handover, and release decision.
