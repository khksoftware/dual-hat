# Canonical Domain Index

This contract answers: which artifact is authoritative for this domain and how does it relate to others?

Each product instantiates rows with: domain; canonical authority; owner; current entrypoint; consumers; dependencies; generated projections; historical surfaces; superseded paths; lifecycle; update trigger; and validation. One domain has one active authority. A physical inventory is not a semantic router, and an entrypoint list is not a second authority.

Minimum domains are architecture decisions, requirements, models, ontology/terminology, schemas, specifications, workflows, data/storage, runtime, tests, templates, governance, engineering process, planning, technical debt, repository ownership, validation, sessions/handover, workspace, archives, packaging, and publication.
