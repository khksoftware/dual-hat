# Extension Model

Create a product profile that binds generic roles to current paths, commands, validation groups, protected assets, branch policy, publication targets, and product-only rules. Reference generic authorities rather than copying them. An extension declares additions, deliberate narrowing, compatibility, validation, update trigger, and retirement. Product runtime remains unaware of Dual Hat administration.

When framework behavior, paths, commands, bootstrap, licensing, drift, or profile rules change, update implementation and help in the same publication. The semantic completeness inventory must identify the profile relationship for every applicable domain.
