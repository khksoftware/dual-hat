# Dual Hat 1.18.3 Release Notes

This compatible governance release strengthens execution continuity without adding unnecessary ceremony. An accepted authorized scope must remain actively tracked until its planned scope reaches a terminal receipt or a named hard-stop gate is proven.

Delegated workers now require authoritative persistent registration, count reconciliation, heartbeat and cursor evidence, and objective state evidence for finish, stall, death, or unreachability. An incomplete worker may be discharged only after its successor is registered. Bounded completion remains the standard: optional perfection work must not delay completion of the authorized scope.
