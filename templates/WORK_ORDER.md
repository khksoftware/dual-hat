# CAPABILITY-NNN Work Order

## Objective

State the user-visible result and durable architectural objective.

## Verified entry state

Record canonical branch, commit, cleanliness, active lifecycle state, and protected assets.

## Authority and boundaries

List in-scope surfaces, explicit non-goals, hard stops, human-decision gates, external-write authority, and publication policy.

## Acceptance and validation

Define focused, integration, committed-tree, export, documentation, dependency, security, and artifact-disposition gates proportional to risk.

## Closure

Require conformance evidence, automatic exit reporting, current handover, clean publication truth, and the exact next gated capability.
